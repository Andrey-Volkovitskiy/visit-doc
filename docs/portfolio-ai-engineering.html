visitdoc.app: AI Engineering

A chat assistant for a medical clinic that helps patients manage appointments and answers policy questions. A LangGraph agent splits each message into requests and handles them in parallel, each on the cheapest model that can do the job. Answers come only from retrieved, cited sources, every change is measured against a golden set, and when the assistant can't answer safely, a person is called instead of a guess.

Agent flow (LangGraph)

  • Multi-topic message processing: the classifier splits a patient message into several self-contained requests, each handled by a specialist node in parallel, so one reply can book an appointment and answer a clinic policy question.
  • Cost-aware model selection: cheap and fast Haiku model for classifying, more capable Sonnet for stating facts and booking.
  • Tools over two transports: the in-house agent's seven tools reach the scheduling service over gRPC. An external agent, the Claude mobile app, gets staff tools over MCP (OAuth 2.1), so staff away from the desk see which chats need attention.

RAG flow: answer only when it's grounded

  • Hybrid search: semantic + BM25 keyword search. Of the two merge strategies measured on the golden set, RRF lost 3 answers and adding BM25's top 3 to the semantic top 5 lost none, so addition ships.
  • Structure-aware chunking: documents are cut at their headings, one chunk per section, each prefixed with its heading path, so a retrieved chunk keeps the context of the section it came from.
  • Grounded FAQ answers: the model answers only from retrieved clinic policy and hands uncovered questions to staff instead of guessing. Citations show staff which policy sections each answer drew on.

Data-driven decisions

  • A golden set of 146 labelled cases and an evaluation harness that drives them through the real stack, so every change to the flow, a prompt or a setting gets a side-by-side comparison with the baseline. A measured noise band separates a real improvement or regression from the model's ordinary run-to-run variation.
  • Tuned by measurement, not by intuition: the evaluation drove the prompt improvements, the rerank floor (calibrated at 0.58) and a temperature for the classifier. Unserved answerable requests fell from 12/87 to 1/87.
  • Langfuse traces cost and latency per step, and guided prompt caching that cut model costs by 45%.

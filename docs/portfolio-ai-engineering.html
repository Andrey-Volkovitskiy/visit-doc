VisitDoc: AI engineering

A chat assistant for a medical clinic: patients manage appointments and ask policy questions in plain language. A LangGraph agent splits each message into requests and handles them in parallel, each on the cheapest model that can do the job. Answers come only from retrieved, cited sources, every change is measured against a golden set, and when the assistant can't answer safely, a person is called instead of a guess.

Agent flow (LangGraph)

  • The specialist nodes run in parallel, and each sees only its own requests, so one question can't leak into another's answer. The model is chosen per node for cost: cheap and fast Haiku for classifying and chatting, more capable Sonnet for anything that states a fact or changes a booking.
  • Tools over two transports: the in-house agent's seven tools reach the scheduling service over gRPC. An external agent, the Claude mobile app, gets staff tools over MCP (OAuth 2.1), so staff away from the desk see which chats need attention.

RAG flow: answer only when it's grounded

  • Structure-aware chunking: documents are cut at their headings, one chunk per section, each prefixed with its heading path, so a retrieved chunk keeps the context of the section it came from.
  • FAQ citations come from the retrieval structure, not from the LLM, so the model can't invent a source. A verdict is stored per request, so a two-question message can answer one and pass the other to staff.

Data-driven decisions

  • A golden set of 146 labelled cases and an evaluation harness that drives them through the real stack, so every change to the flow, a prompt or a setting gets a side-by-side comparison with the baseline. A measured noise band separates a real improvement or regression from the model's ordinary run-to-run variation.
  • Tuned by measurement, not by intuition: the evaluation drove the prompt improvements, the retrieval thresholds (the rerank floor calibrated at 0.58, the similarity floor removed) and a temperature for the classifier. Unserved answerable requests fell from 12/87 to 1/87.
  • Langfuse traces the cost and latency of every step of the flow. Prompt caching, added where the traces showed the spend, cut model costs by 45%.
